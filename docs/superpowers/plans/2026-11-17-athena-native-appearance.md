## A1. Prove one native glass panel

**Files.** Add examples/glass_spike.rs and examples/shaders/wallpaper_glass.wgsl. Document results in docs/design/athena-glass-spike.md. Use the existing eframe re-exports of egui-wgpu and wgpu. The spike needs no new dependency.

- [ ] Confirm the actual renderer through CreationContext.wgpu_render_state, using egui-wgpu 0.37.0 matched to eframe/egui and the existing wgpu 30.0.1 resolution. Capture the adapter and backend. Use a deterministic bright/dark texture and one panel. Compare solid, tint, and shader paths in the same harness.
- [ ] Paint the wallpaper with shared crop math and sample that texture in a rounded panel. Use callback preparation for any lower-resolution separable blur. Reuse the blur result for all consumers. Pass physical scale, clip and UVs explicitly. Put ordinary text, input and focus cues above the sampled material. Test static resize and 100/125/150/200% DPI. Inspect the actual target format, use the color encoding and premultiplied blend convention expected by egui, and test transparent pixels and clipping at edges. Current egui-wgpu uses gamma-encoded output with its usual non-sRGB target. Compare composited pixels with the solid/tint reference.
- [ ] Run cargo run --release --example glass_spike. Measure on a named Windows device at 1920×1080 and its recorded DPI. Compare CPU/GPU frame time and peak/resident memory across modes. Proposed acceptance is p95 interactive frame time at most 16.7 ms at 60 Hz with no continuous repaint after idle, no text distortion, and a solid fallback on absent renderer resources. Record failures and adapter/driver. If the effect misses a gate, default to solid/tint and keep media work independent of it.

## A3. Implement managed media and bounded playback

**Files.** Add src/infrastructure/media/{mod.rs,decode.rs,assets.rs}, src/ui/appearance/{mod.rs,background.rs}, and connect src/app/mod.rs and src/ui/shell.rs. Enable only PNG, JPEG and GIF decoding in an explicit image 0.25.10 dependency after confirming lockfile features.

- [ ] Define decoder input/output with opaque request ID, checked dimensions, shared frame ownership, duration/loop metadata and localized failure classes. Cap actual source reads at 16 MiB, source dimensions at 2048 each, decoded frames at 300, and combined retained RGBA at 128 MiB across active and preview. Charge each frame before retention and separately record peak decoder scratch buffers and GPU capacity. Use bounded decoder limits as a second guard. Evaluate a browser-like 100 ms replacement for delays at or below 10 ms and cap presentation independently at 30 fps. Treat the delay and loop behavior as decisions and cover zero, short, finite and missing-loop cases in fixtures. The limits are independent ceilings. A 2048×2048 RGBA frame alone consumes 16 MiB, so typical animations must downscale while streaming frames through the decoder, then reject if the selected tier cannot fit the aggregate budget. Use elapsed time with cumulative frame delays and finite loop completion. Verify disposal/transparency, truncated/oversize data, zero delays, 301 frames and aggregate overflow in deterministic tests.
- [ ] Run a bounded worker with one in-flight decode and only the latest queued request. Superseded/cancelled results carry stale generations and are dropped. Closing preview, Reset, import, restore and active session replacement invalidate generations. Preview reuses decoded buffers and never changes the committed wallpaper until Apply. Add tests for late results, replacement races, cancellation and a preview that exceeds the combined budget.
- [ ] Stage and verify app-owned copies under root/appearance, then promote an opaque asset ID on apply. Publish the file before committing the DB reference so failure can only leave an unreferenced app-owned file. Remove only staged work or provably unreferenced app-owned files. Retain assets referenced by supported kept local backups, or document explicit removal behavior and solid fallback before enabling collection. Never follow an arbitrary stored path. Test failed commits, old snapshots, portable moves, invalid IDs, missing files, and source-file preservation.
- [ ] Own one playback clock and at most two shared wallpaper textures per active shell or bounded preview. Draw with a background painter behind transparent shell chrome, opaque reading surfaces, and a minimum scrim. Define Fit/Fill UV math once for shell and preview. Freeze to a poster under reduced motion. Suspend on minimize/hidden and pause on blur by default. Resume elapsed playback without catch-up, request re-paint only when a frame or state will change, and avoid uploading unchanged frames. Verify Month, Calendar, Settings and Trash preserve frame index and scroll/focus across navigation. Future Goals uses the same shell. Test zero decorative repaints while paused and no report query reload caused by animation.
