# Athena 1.0.1 Implementation Plan

> **Historical plan:** `v1.0.1` is already present on the remote at `3b934e3`, including the later Semibold/Bold and category-layout changes. See the [1.0.1 reconciliation](../specs/2026-11-13-athena-1.0.1-revision-brief.md) for the observed implementation and the [1.0.2 brief](../specs/2026-11-13-athena-1.0.2-revision-brief.md) for remaining corrections. Do not execute this historical plan to rebuild or move the published tag.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Athena 1.0.1 as the type-and-design foundation: the approved designer brief in the repository, the pinned Salted Flutters Polaris family embedded in the app, a frozen tabular face for money, deterministic snapshots, and a clean patch release. No flow, storage, or business rule changes.

**Architecture:** `src/ui/theme/typography.rs` builds egui font definitions from fonts embedded with `include_bytes!`. The real app adds Segoe UI and Segoe UI Symbol after Polaris as glyph fallbacks; snapshot tests install only Polaris plus egui's bundled fallbacks, so they do not depend on host fonts. `apply_text_styles` maps body, button, section, heading, display, and money to the right Polaris face. Font assets are generated once by `tools/fonts/build.py` and committed; Cargo never runs Python and never downloads a font.

**Tech Stack:** Rust 2024, eframe/egui 0.37, `ttf-parser` 0.25 as a dev-dependency, fontTools 4.68 for the one-off font build.

**Spec:** `docs/superpowers/specs/2026-11-11-athena-design.md`

**Brief:** `docs/design/athena-designer-brief.md` (also reproduced in Appendix A)

**Base:** Athena 1.0.0, commit `7e02a59`, tag `v1.0.0`, clean working tree.

## Scope

In scope:

- Add the final 3,992-character designer brief as a first-class repository document.
- Vendor three Polaris text weights (Regular, Medium, Semibold) plus one frozen-tabular Regular face.
- Include the upstream license unchanged, preserve the required metadata line, and rename modified families to avoid using the upstream primary family name.
- Embed the fonts, add the tabular money family, and apply the type scale.
- Regenerate the UI snapshots with embedded fonts.
- Bump the app, installer, README, design spec, and smoke checklist to 1.0.1.
- Tag `v1.0.1` after verification.

Out of scope:

- The redesign described in the brief. The brief guides later versions; 1.0.1 only installs the type foundation.
- New screens, flows, icon sets, motion, data model changes, migrations, or 1.1/1.2 features.
- Any runtime file dependency for Polaris, any network call, or any font download during build.

## Global Constraints

- Rust edition `2024`, `rust-version = "1.95"`.
- `[lints.rust] unsafe_code = "warn"`. `[lints.clippy] all = "warn"`, `pedantic = "warn"`.
- All visible copy stays in `src/i18n`; this release adds no visible strings.
- Money stays exact `i64` cents, displayed as `R$ 1.234,56`. Tabular figures are a rendering concern only.
- No SQL, schema, migration, or stored-data change.
- No change to keyboard behavior: `Ctrl+N`, `Enter`, `Esc`, and visible focus stay as they are.
- Polaris is embedded. The release executable must not read font files from the install directory.
- The upstream `LICENSE.txt` is byte-identical; the required metadata line remains in every style.
- The four generated font files are subsets, each under 250 KB; do not commit the original 3.4 MB styles.
- The brief is under 4,000 characters. The approved text is 3,992 characters; do not grow it in this release.
- Snapshots must be deterministic: embedded fonts plus egui defaults, never host system fonts.
- No stale version strings remain outside historical plans, tags, and notes.
- Every task ends with `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, and the relevant tests.

## Review Focus

1. **License compliance:** `assets/fonts/LICENSE.txt` is the unmodified upstream license; every font carries `Salted Flutters Polaris - Created by ppoolar`; modified families are named `Athena Polaris`, never `Salted Flutters Polaris`.
2. **Font identity:** Regular is body text, Medium is buttons, Semibold is section/heading/display, and the tabular face is the only money/dates face.
3. **Tabular money:** digits in `R$ 1.234,56` have one advance width; amounts and table dates align in both themes.
4. **Language coverage:** Portuguese diacritics (`ã õ ç á é í ó ú â ê ô à ü`) render at 13 px and 15 px without tofu or clipping.
5. **Fallback symbols:** `↩` (refund), `⌕` (search), and the sidebar glyphs `☰`, `▦`, `⚙` are absent from Polaris. At runtime they must resolve through Segoe UI Symbol. Snapshots are deterministic and may show tofu for glyphs that no bundled font covers; review them for text and layout, not for those host-only icons. `⌕` appears only in the filtered empty state, which snapshots do not exercise.
6. **Snapshot determinism:** tests use `install_test_fonts`, not the Windows font folder; all ten images are intentionally reviewed.
7. **Layout:** the denser Polaris metrics do not clip English or pt-BR labels, overflow cards, or break right-aligned amounts at 1100×760.
8. **Release consistency:** Cargo, installer, README, sidebar version, and the 1.0.1 smoke section all say 1.0.1.

```rust
//! Validates the committed font assets. The build never downloads a font.

use ttf_parser::{Face, name_id};

const REGULAR: &[u8] = include_bytes!("../assets/fonts/AthenaPolaris-Regular.otf");
const MEDIUM: &[u8] = include_bytes!("../assets/fonts/AthenaPolaris-Medium.otf");
const SEMIBOLD: &[u8] = include_bytes!("../assets/fonts/AthenaPolaris-Semibold.otf");
const TABULAR: &[u8] = include_bytes!("../assets/fonts/AthenaPolaris-Tabular.otf");
const LICENSE: &str = include_str!("../assets/fonts/LICENSE.txt");

const FACES: [(&str, &[u8]); 4] = [
    ("Regular", REGULAR),
    ("Medium", MEDIUM),
    ("Semibold", SEMIBOLD),
    ("Tabular", TABULAR),
];

fn name(face: &Face<'_>, id: u16) -> String {
    face.names()
        .into_iter()
        .find(|name| name.name_id == id && name.is_unicode())
        .and_then(|name| name.to_string())
        .unwrap_or_else(|| panic!("missing name id {id}"))
}

fn digit_widths(face: &Face<'_>) -> Vec<u16> {
    "0123456789"
        .chars()
        .map(|ch| {
            let glyph = face
                .glyph_index(ch)
                .unwrap_or_else(|| panic!("missing digit {ch}"));
            face.glyph_hor_advance(glyph)
                .unwrap_or_else(|| panic!("missing advance for {ch}"))
        })
        .collect()
}

#[test]
fn faces_are_subsets_with_the_required_metadata() {
    for (file, bytes) in FACES {
        assert!(bytes.len() < 250_000, "{file} is not a subset");
        let face = Face::parse(bytes, 0).unwrap_or_else(|err| panic!("{file}: {err:?}"));
        assert_eq!(
            name(&face, name_id::COPYRIGHT_NOTICE),
            "Salted Flutters Polaris - Created by ppoolar",
            "{file} lost the required metadata line"
        );
        // The upstream files have no typographic-family record (name ID 16); name ID 1 is the
        // family that applications actually show. The builder renames it.
        assert!(
            !name(&face, name_id::FAMILY).contains("Salted Flutters Polaris"),
            "{file} still uses the upstream primary family name"
        );
    }

    let regular = Face::parse(REGULAR, 0).unwrap();
    let tabular = Face::parse(TABULAR, 0).unwrap();
    assert_eq!(name(&regular, name_id::FAMILY), "Athena Polaris");
    assert_eq!(name(&tabular, name_id::FAMILY), "Athena Polaris Tabular");
}

#[test]
fn every_face_covers_athena_text() {
    const COVERAGE: &str = "R$ 1.234,56 − + ãõçáéíóúâêôàü • … × → ✓";
    for (file, bytes) in FACES {
        let face = Face::parse(bytes, 0).unwrap();
        for ch in COVERAGE.chars().filter(|ch| !ch.is_whitespace()) {
            assert!(
                face.glyph_index(ch).is_some(),
                "{file} lacks required glyph {ch:?}"
            );
        }
    }
}

#[test]
fn tabular_digits_share_one_advance() {
    let tabular = Face::parse(TABULAR, 0).unwrap();
    let widths = digit_widths(&tabular);
    assert!(
        widths.windows(2).all(|pair| pair[0] == pair[1]),
        "tabular digits differ: {widths:?}"
    );

    let regular = Face::parse(REGULAR, 0).unwrap();
    let mut proportional = digit_widths(&regular);
    proportional.sort_unstable();
    proportional.dedup();
    assert!(
        proportional.len() > 1,
        "Regular digits should stay proportional"
    );
}

    assert!(!LICENSE.contains('\r'));
```

```python
#!/usr/bin/env python3
"""Build Athena's pinned Salted Flutters Polaris subsets.

This is a one-off asset step, not part of `cargo build`. Requires fontTools 4.68+.

    git -c core.autocrlf=false clone https://github.com/ppolkadot/Salted-Flutters-Polaris.git
    git -c core.autocrlf=false -C Salted-Flutters-Polaris checkout e4d7c2f56c0aff6c6ff1d0751f17cf146a5ecfde
    python tools/fonts/build.py --source-dir Salted-Flutters-Polaris --out-dir assets/fonts
"""

from __future__ import annotations

import argparse
from pathlib import Path

from fontTools import subset
from fontTools.ttLib import TTFont

STYLES = ("Regular", "Medium", "Semibold")
TABULAR_SOURCE = "Regular"
COPYRIGHT = "Salted Flutters Polaris - Created by ppoolar"

# Basic Latin, Latin-1, Latin Extended-A, general punctuation, currency, arrows and the
# symbols Athena uses. This keeps Portuguese, R$, minus, arrows and bullets.
CHARS = "".join(
    chr(cp)
    for cp in (
        list(range(0x20, 0x7F))
        + list(range(0xA0, 0x180))
        + list(range(0x2000, 0x2070))
        + list(range(0x20A0, 0x20D0))
        + list(range(0x2190, 0x2200))
        + [0x2212, 0x2260, 0x2264, 0x2265, 0x25CF, 0x25CB, 0x2713]
    )
)


def source_path(source_dir: Path, style: str) -> Path:
    return source_dir / f"SaltedFluttersPolaris-{style}.otf"


def subset_font(source: Path) -> TTFont:
    options = subset.Options()
    options.layout_features = ["*"]
    options.name_IDs = ["*"]
    options.name_legacy = True
    options.name_languages = ["*"]
    options.notdef_outline = True
    options.recalc_bounds = True
    options.recalc_timestamp = False
    options.drop_tables += ["MERG", "meta", "trak"]
    font = subset.load_font(source, options)
    subsetter = subset.Subsetter(options=options)
    subsetter.populate(text=CHARS)
    subsetter.subset(font)
    font.recalcTimestamp = False
    return font


def rename(font: TTFont, family: str, style: str) -> None:
    values = {
        1: family,
        2: style,
        3: f"{family} {style}; 1.001; ATHENA; 2026-11-13",
        4: f"{family} {style}",
        6: f"{family.replace(' ', '')}-{style}",
        16: family,
        17: style,
    }
    for record in font["name"].names:
        if record.nameID in values:
            record.string = values[record.nameID]


def freeze_tabular_digits(font: TTFont) -> None:
    order = set(font.getGlyphOrder())
    for table in font["cmap"].tables:
        for codepoint in range(0x30, 0x3A):
            if codepoint not in table.cmap:
                continue
            alternate = table.cmap[codepoint] + ".tnum"
            if alternate in order:
                table.cmap[codepoint] = alternate

    cmap = font.getBestCmap()
    widths = {
        font["hmtx"][cmap[codepoint]][0]
        for codepoint in range(0x30, 0x3A)
    }
    if len(widths) != 1:
        raise SystemExit(f"tabular digits do not share one advance: {sorted(widths)}")


def save(font: TTFont, out_dir: Path, name: str) -> None:
    target = out_dir / name
    font.save(target)
    check = TTFont(target)
    copyright = check["name"].getDebugName(0)
    if copyright != COPYRIGHT:
        raise SystemExit(f"{name}: copyright line changed: {copyright!r}")
    print(f"{name}: {target.stat().st_size} bytes, {len(check.getGlyphOrder())} glyphs")


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--source-dir", type=Path, required=True)
    parser.add_argument("--out-dir", type=Path, required=True)
    args = parser.parse_args()
    args.out_dir.mkdir(parents=True, exist_ok=True)

    for style in STYLES:
        font = subset_font(source_path(args.source_dir, style))
        rename(font, "Athena Polaris", style)
        save(font, args.out_dir, f"AthenaPolaris-{style}.otf")

    font = subset_font(source_path(args.source_dir, TABULAR_SOURCE))
    freeze_tabular_digits(font)
    rename(font, "Athena Polaris Tabular", "Regular")
    save(font, args.out_dir, "AthenaPolaris-Tabular.otf")


if __name__ == "__main__":
    main()
```

The script performs three jobs: it keeps Latin and Portuguese, it renames modified families so the upstream primary family name is not used, and it freezes `tnum` by remapping digits to the existing `.tnum` glyphs. egui 0.37 does not expose OpenType feature selection, so freezing is what makes the money face tabular.

````markdown
# Athena — Designer Brief

## Product
Athena is a local-first desktop finance app for one person or a household. It runs offline on Windows, stores data in one SQLite file, and focuses on fast expense logging and clear monthly review. Money is BRL, exact cents. UI is English and Brazilian Portuguese at runtime. Shipped through 1.4 (Goals and closings).

## Users and feel
Individual tracking daily spending; couple sharing expenses by responsibility; desktop, keyboard-first. Light, quiet, fast. Entry faster than a notes app. No dashboard clutter.

## Core jobs
1. Log an expense in under 10 seconds.
2. See where the month's money went.
3. Browse the year by month; drill into a month/day.
4. Know who owes whom (1.1).
5. Track goals without mixing them into expenses (1.4).
6. Close a completed month and compare later (1.4).
7. Trust local data, backups, exports.

## Screens
- Onboarding: 4 steps.
- Month: stepper, all-time balance, income/expenses/result cards, insight, filters, day-grouped register, right rail with category bars, person totals, settlement, saved closing card (changed marker).
- Calendar: 12 month cards with saved/changed closing markers, day drill-down.
- Goals (Ctrl+5): lifecycle tabs, list and detail, contributions, Funded apart from Completed. Trash, Settings (Appearance: wallpaper, text size).
- Quick add modal: amount first, then title/date/type/category/payer/person/split; Enter saves, Esc closes.
- Global: sidebar (Month, Calendar, Goals, Trash, Settings; Ctrl+1–5 hints), toasts/undo, confirm dialogs, empty states.

## Type
Shipped: Salted Flutters Polaris (github.com/ppolkadot/Salted-Flutters-Polaris), embedded Latin subsets.

- `Semibold` for body and controls; real `Bold` (`usWeightClass = 700`) for wordmark, section, heading, display, and month titles.
- Money/dates use frozen `tnum` `Tabular Semibold`. Right-align amounts.
- Glyph fallbacks: `Segoe UI` and `Segoe UI Symbol` for symbols beyond the Latin subset.
- Sizes: 15 body, 13 secondary, 20 section, 28 heading, 34 display. Keep 8 pt grid.
- Keep `LICENSE.txt` beside redistributed fonts.

## Must not break
- Windows desktop, egui 0.37, offline.
- Exact BRL `R$ 1.234,56`; no implied rounding; right-aligned tabular amounts.
- Keyboard-first: `Ctrl+N`, `Enter`, `Esc`, visible focus.
- Shared expense shows responsibility vs payment; never double-count.
- English and pt-BR fit without truncation; runtime switch.
- Contrast holds for body, muted, accent, positive/negative in both themes.
- Wallpaper keeps text 4.5:1, cards opaque; Reduced motion/High contrast win.
- No accounts, transfers, bank sync, budgets, recurring rules, AI advice, attachments.
````
