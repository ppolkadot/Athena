# Athena 1.2.0 — Daily speed

> **Status:** Draft executable plan aligned with [contracts.md](../specs/contracts.md) D9, §2, and §14.1. Do not bump `Cargo.toml` or begin 1.2 product feature commits until baseline Gate 0 is approved and §14.1 is promoted to frozen in [contracts.md](../specs/contracts.md).

**Goal.** Speed up everyday entry and review without sacrificing data integrity: full-fidelity templates, one-line quick entry, duplicate consent, day drill-down, structured monthly insights, verified XLSX export, and shared design tokens with an embedded icon set.

**Baseline.** Built on shipped `v1.1.0` (`migrations/0003_trash.sql`, document format `2`, SQLite `application_id = 0x41544E41`) plus the post-`v1.1.0` readiness fixes: explicit per-version import dispatch (`1 => DocumentV1`, `2 => DocumentV2`), byte-stable [format1-1.0.2.json](../../../tests/fixtures/format1-1.0.2.json) and [format2-1.1.0.json](../../../tests/fixtures/format2-1.1.0.json), restart-reconcilable recovery, and packaging SHA/provenance metadata.

**Release boundaries.**
- **1.2.0 owns:** `migrations/0004_templates.sql` (schema version `4`), document format `3` (`DocumentV3`), XLSX export, design tokens, and embedded icons.
- **Out of scope:** wallpaper/GIF playback, theme presets, glass compositor, and `0005_appearance` (reserved for **1.3.0**); savings goals, closings, `0006_goals`, `0007_closings`, and format `5` (reserved for **1.4.0** per D9).
