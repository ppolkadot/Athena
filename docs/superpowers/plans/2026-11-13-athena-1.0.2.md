# Athena 1.0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Athena 1.0.2 to resolve normal-sized semantic text contrast (including composited selection states), reconcile the font provenance and upstream Bold `OS/2.usWeightClass` metadata quirk, verify adaptive overflow/layout behavior at `1100×760`, `760×560`, and `100%–200%` scaling, refresh snapshots, and build/verify the 1.0.2 executable and installer without altering the published `v1.0.1` tag.

**Architecture:** Palette and theme state contrast fixes stay inside `src/ui/theme/{palette.rs,mod.rs}`. Font metadata normalization stays inside `tools/fonts/build.py` and `assets/fonts/`. Overflow protection reserves the right-hand controls (`person_pill`, `amount`, `Edit`/`Delete`) before laying out title and category in `src/ui/components/transaction_row.rs`, and falls back cleanly when horizontal width is tighter than the amount column in `src/ui/screens/month.rs::rail_row` and `src/ui/quick_add.rs`. No schema changes, new screens, or financial logic changes.
